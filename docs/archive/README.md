# Archivo documental

Este directorio preserva material historico, educativo o supersedido.

## Regla de uso

- No tratar estos documentos como contrato operativo vigente.
- Si un archivo archivado contradice `README.md`, `AGENTS.md` o una doc activa, prevalece la documentacion activa y el codigo real.
- Algunas referencias internas pueden describir estados viejos, decisiones exploratorias o branding previo.

## Secciones archivadas

- `blog-carrito-mercadopago/`: serie educativa sobre carrito, checkout y Mercado Pago.
- `maintenance-mode/`: visuales, quickstarts y resumentes historicos de maintenance mode.
- `payments-webhooks/`: guias extendidas, quick references y material de reconciliacion desplazado por docs activas mas chicas.
- `operations/`: documentos operativos viejos o redundantes.
